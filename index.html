Lesson 1: Phonetics

1. Introduction to Pinyin & Syllables

Each Chinese character usually represents a single syllable. For example, the character 你 (you) has the Pinyin nǐ.

The Components of Pinyin

A Chinese syllable is made up of three parts:

  • Initial: The consonantal beginning of a syllable.
  • Final: The part of the syllable excluding the initial.
  • Tone: One of the 4 tones (or neutral tone) placed on the main vowel.
n + i + ˇ = nǐ

2. The Four Tones

Different Tones may express entirely different meanings.
For example: mā (mother) vs. mà (scold).

Tone Mark Description Sound Concept
1st Tone ā Flat tone Sounds like a robot (ēēēē)
2nd Tone á Rising tone Sounds confused (like asking "Huh?")
3rd Tone ǎ Falling-Rising tone Like a small rollercoaster (voice goes down, then up)
4th Tone à Falling tone Sounds angry OR sounds like you got stepped on!
Neutral a No mark Light, short, soft. Used in continuous speech (e.g., ma, de)

5. Pinyin Spelling Rules

Rule 1: Use of "y" and "w"

  • If i is the main vowel, add y (i → yi). If it's NOT the main vowel, replace with y (ian → yan).
  • If u is the main vowel, add w (u → wu). If it's NOT the main vowel, replace with w (uan → wan).

Rule 2: Dropping the dots on "ü"

The letters j, q, and x already create a similar sound to "ü". Therefore, when they combine with "ü", the two dots are OMITTED:

  • j + ü = ju (e.g., jù 句)
  • q + ü = qu (e.g., qù 去)
  • x + ü = xu (e.g., xǔ 许)

Note: "j, q, x" NEVER combine with a, o, e, u. Also, when "ü" stands alone (no initial), add "y" and drop the dots (üan → yuan).

Rule 3: Tone Mark Placement

  • Place it on the main vowel in this priority order: a → o → e → i → u → ü (e.g., bāi, guó, guǎi).
  • If on the vowel "i", omit the dot (e.g., yín).
  • For "iu" and "ui", place it on the last vowel (e.g., tuī, qiú).

Rule 4: Dividing Mark (') & Capitalization

  • Use the dividing mark (') when a syllable starting with "a, o, e" follows another syllable to avoid confusion (e.g., Tiān'ānmén vs. Tiānānmén).
  • Syllables forming the same word are written together (e.g., bà ba → bàba).
  • Capitalize proper nouns and the first letter of sentences (e.g., Lín Nà).
